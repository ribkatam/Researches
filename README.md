## 1. Pattern Formation and Retrieval in a Reduced-Scale CA3-Inspired Neural Network

**Type:** M.S. Thesis  
**Institution:** The George Washington University  
**Degree:** M.S. in Electrical Engineering  
**Indexing:** ProQuest

### Overview

This thesis investigates pattern formation and retrieval in a reduced-scale neural network inspired by the **CA3 region of the hippocampus**.

The work focuses on computational modeling of recurrent neural dynamics and associative-memory behavior while exploring how a substantially reduced network can preserve meaningful functional properties.

### Research Focus

- Recurrent spiking neural networks
- Associative memory and pattern retrieval
- Neural dynamics and computational neuroscience
- GPU-accelerated simulation
- Model reduction and optimization
- Quantitative evaluation of retrieval performance

### Technical Highlights

- Developed and evaluated a GPU-accelerated recurrent neural-network simulation.
- Designed multi-objective evaluation criteria to distinguish meaningful retrieval behavior from misleading metric improvements.
- Used large experimental sweeps and optimization techniques to study model behavior.
- Investigated numerical differences between CPU and GPU execution by tracing behavior through C++/CUDA simulation internals.
- Explored reduced-scale network configurations while preserving target associative-memory behavior.

## 2. Cyberbiosecurity Risk Assessment Framework for Genomic Data Storage in Cloud Environments

**Venue:** IEEE Symposium on Security and Privacy Workshops  
**Year:** 2026

### Overview

This work presents a **cyberbiosecurity risk assessment framework for genomic data stored in cloud environments**.

Genomic data introduces unusual security and privacy challenges because it is highly sensitive, persistent, uniquely identifying, and valuable across healthcare, research, and biotechnology. The project examines how traditional cloud-security concerns intersect with risks specific to genomic information.

### Research Focus

- Cyberbiosecurity
- Genomic data security
- Cloud security
- Privacy and confidentiality
- Risk assessment
- Threat modeling
- Secure data storage

### Key Themes

- Identifying threats affecting genomic data across cloud storage environments.
- Structuring cyberbiosecurity risks into a practical assessment framework.
- Examining confidentiality, integrity, availability, privacy, and long-term sensitivity of genomic information.
- Connecting technical cloud-security controls with the unique characteristics of biological data.

## 3. Security-Aware Residual Fusion for Infrastructure-as-Code Misconfiguration Detection

**Venue:** 8th International Conference on Computer and Communication Technologies

### Overview

This research explores a machine-learning approach for detecting security misconfigurations in **Infrastructure-as-Code (IaC)**.

The work focuses on learning security-relevant patterns from infrastructure configuration data and combining representations through a **security-aware residual fusion** approach to improve misconfiguration detection.

### Research Focus

- Infrastructure-as-Code security
- Security misconfiguration detection
- Machine learning for cybersecurity
- Learned code representations
- Representation fusion
- Automated security analysis

### Technical Direction

- Preprocessing and analyzing Infrastructure-as-Code configuration data.
- Learning representations of security-relevant configuration patterns.
- Comparing baseline and learned feature representations.
- Applying residual fusion to combine complementary security signals.
- Evaluating classification quality using precision, recall, F1-score, confusion matrices, and related metrics.
- Studying whether learned security patterns improve detection beyond conventional feature-based approaches.

### Tools and Methods

- Python
- Machine learning and deep learning
- Code embeddings
- TF-IDF baselines
- Security-oriented feature engineering
- Classification and model evaluation
- Reproducible experimentation
